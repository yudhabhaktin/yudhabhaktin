# Yudha Bhakti Nugraha

Cloud and data architect in Jakarta. Seven years designing and shipping systems that
reached production — streaming platforms, cloud data platforms, computer vision on edge
devices, and LLM applications — across agribusiness, toll road operations, and
telecommunications.

Most recently Digital Product Development Lead at Sinar Mas Agribusiness and Food
(PT SMART Tbk). B.Sc. Computer Science and Electronics, Universitas Gadjah Mada.

**Most of my work sits in private and enterprise repositories.** This page is the
context for what isn't here.

## Selected work

**Treasury reporting across 1,700+ bank accounts** — Automated cash balance reporting and
DHE SDA regulatory transactions across multiple banking channels and customs systems.
Retired roughly 4,000 person-hours of manual reconciliation a year.

**Enterprise cloud data platform** — Consolidated scattered line-of-business sources into
a governed analytics stack on GCP and BigQuery with modeled dbt transformation layers.

**RAG assistant, 300+ daily users** — LLM application on Azure using vector search and
hybrid retrieval over SQL transaction data and unstructured compliance documents.
Deployed across six refineries.

**Vehicle classification at 60 toll gates** — PyTorch models optimized with TensorRT on
edge devices, fused with LiDAR input, streaming classification events into Electronic
Toll Collection. Led the program end to end with government stakeholders.

**Industrial IoT platform, 1M+ events/day** — Telemetry pipelines in Go and Python over
RabbitMQ, time-series storage in InfluxDB, document storage in MongoDB, feeding real-time
OEE dashboards. Founding engineer at Evomo, incubated inside Telkom Indonesia.

**GitHub Enterprise migration** — 100+ repositories, 70+ developers and 10+ teams moved in
three months, architected around data residency constraints with Entra ID for identity
and access governance.
